intval函数

函数签名

特性一：字符串解析规则

· 从字符串开头提取数字
· 遇到非数字字符立即停止
· 如果开头不是数字，返回 0

特性二：自动进制识别（$base = 0）

· “0x” 开头 → 十六进制
· “0b” 开头 → 二进制
· “0” 开头 → 八进制（PHP 7+ 可能失效）
· 其他 → 十进制

特性三：数组转换

· 空数组 [] → 0
· 非空数组 [任何值] → 1

特性四：其他类型

· true → 1
· false → 0
· null → 0
· 浮点数 → 向下取整

与弱/强比较结合

· === 严格比较：值和类型都必须相等
· == 弱比较：自动类型转换

应用场景

场景 绕过方式
禁止 “4476” 字符串 用 “4476a” 或 “0x117c”
需要 intval 结果非零 传非空数组 ?num[]=
需要 intval 等于某数 用截断或进制转换

正则表达式

结构：/匹配规则/修饰符

· 第一个 /：开始
· 中间：匹配规则
· 第二个 /：结束
· 后面：修饰符，控制匹配方式

^ 和 $

^ 开头
$ 结尾

i 修饰符

· 不区分大小写
· php 能匹配 PHP、Php、pHp 等

m 修饰符

· 多行模式
· 让 ^ 和 $ 按“行”来算，不是按整个字符串
· 没有 m：^ 只匹配整个字符串的开头，$ 只匹配整个字符串的结尾
· 有 m：^ 能匹配每一行的开头，$ 能匹配每一行的结尾
· 换行符是 \n（URL 里写成 %0a）

strpos()

是什么

strpos() 是 PHP 内置函数，用于在字符串中查找某个字符或子串第一次出现的位置。

格式

返回值

· 找到且位置是开头 → 返回 0
· 找到且位置在其他地方 → 返回 1、2、3…（从 0 开始计数）
· 没找到 → 返回 false

举例

常见用法搭配 ! 取反

!strpos($str, “0”) 为真的情况：

· 没找到 “0”（返回 false，取反得 true）
· “0” 在开头（返回 0，取反得 true）

!strpos($str, “0”) 为假的情况：

· “0” 在其他位置（返回正整数，取反得 false）

md5()

基本概念

md5() 是 PHP 内置函数，用于计算字符串的 MD5 哈希值。

输出格式

· 固定长度：32 个字符
· 只包含数字 0-9 和字母 a-f（十六进制）

举例

CTF 考点

· 传入数组 → 返回 NULL
· 两个 NULL 弱比较相等 → 绕过
· 两个 0e 开头的哈希值弱比较相等（都等于 0）

一句话总结

md5() 把字符串转成 32 位哈希值，传数组返回 NULL，有 0e 漏洞。

sha1()

基本概念

sha1() 是 PHP 内置函数，用于计算字符串的 SHA1 哈希值。

输出格式

· 固定长度：40 个字符
· 只包含数字 0-9 和字母 a-f（十六进制）

举例

与 md5 的区别

函数 输出长度 特点
md5() 32 位 速度更快
sha1() 40 位 安全性稍高（但已不安全）

CTF 考点

· 和 md5() 完全一样：
· 传入数组 → 返回 NULL
· 两个 NULL 弱比较相等
· 0e 开头字符串可绕过弱比较

一句话总结

sha1() 和 md5() 类似，生成 40 位哈希值，传数组返回 NULL，有 0e 碰撞。
